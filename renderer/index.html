欢迎使用 AOURA 启动器

AOURA 是一款面向 我的世界（Minecraft）Java 版的桌面启动器，由珉爱制作开发。 本文档由 AOURA 团队编写，从安装到启动，手把手带你完成 AOURA 的全部使用流程。

第 1 步 · 安装 AOURA

1
双击安装包 AOURA启动器-Setup-xxx.exe，按提示完成安装。安装目录默认在「Program Files」，也支持自定义安装目录（建议安装到 D 盘等空间充足的磁盘）。
2
安装完成后桌面会生成 AOURA 启动器快捷方式，双击即可打开。
3
首次启动会询问使用离线账户还是微软正版账户，选择后即可开始；之后随时可在「账户」页切换。
小提示：启动器的所有数据、缓存、日志与游戏文件默认存放在安装目录下，卸载时选择"同时删除用户数据"可完全清理。

第 2 步 · 准备 Java 运行环境

1
进入「设置」，找到 Java 环境区域，开启「自动下载 Java」开关。
2
启动器会按你选择的游戏版本自动下载匹配的 Java（老版本用 Java 8，新版本用 Java 17 / 21 / 25）。下载源使用清华 / 南大 / 华为云 / 兰大国内镜像，下载更快更稳。
3
如果你本机已装有 Java，也可以关闭自动下载，点击「选择 Java 路径」手动指定 javaw.exe / java.exe 位置。
小提示：Java 与游戏文件一样存放在启动器安装目录下的 java 文件夹，不占用系统环境变量。

第 3 步 · 下载游戏版本

1
进入「下载中心」，版本清单来自 BMCLAPI 加速镜像与 Mojang 官方，共 900+ 个版本，全部可下载游玩、无试玩版。
2
顶部四个分类：正式版（稳定版）· 快照版（每周开发版）· 特色版（愚人节等官方整活）· 远古版（Alpha / Beta 怀旧）。全部版本一次性完整展示，无需翻页或加载更多，直接往下滚动浏览。
3
点击任意版本卡片，选择「仅下载原版」或「原版 + Fabric / Forge / NeoForge」，确认后开始下载，进度在右下角「下载任务」浮动面板实时显示，任何页面都一眼可见。
小提示：下载完成的版本会自动出现在「版本管理」与主页的版本选择器中。

第 4 步 · 安装模组底层（加载器）

1
进入「版本管理」，选择要安装底层的版本，点击「安装模组底层」。
2
选择加载器：Fabric（轻量、适配多数优化/功能模组）· Forge（经典、兼容老牌大型模组）· NeoForge（Forge 继任者、面向最新版本）。
3
选择加载器版本后点击安装，等待完成；安装成功后该版本即可识别对应加载器的模组。
小提示：安装底层不影响原版启动，版本列表会同时保留原版与带加载器的启动项。

第 5 步 · 获取模组与光影

1
进入「资源中心」，可搜索 Modrinth 开源社区的数万模组、光影、材质包与整合包（如 sodium、iris、SEUS）。
2
输入关键词搜索，筛选分类，点击资源卡片可查看版本、依赖并一键下载。
3
已下载的模组可在「版本管理 → 模组管理」中启用 / 禁用 / 删除；光影包在「光影管理」中管理。
小提示：搭配 MC 百科（mcmod.cn）可查看模组的中文介绍与教程，资源中心顶部有直达按钮。

第 6 步 · 管理存档与光影

1
「版本管理 → 存档管理」会列出该版本的全部世界存档，显示存档名称（读自 level.dat），可「打开存档文件夹」或「删除」。
2
「光影管理」列出已安装的光影包（zip），支持打开文件夹与删除。
3
「整合包管理」支持导入 zip / mrpack 整合包，启动器会自动解压为可启动的版本。
小提示：删除操作前请确认不需要该存档；也可以先打开文件夹手动备份。

第 7 步 · 配置账户

1
「账户」页可设置离线账户名（仅限英文字母 / 数字 / 下划线，1–16 个字符，该名字即游戏内玩家名）并上传自定义头像。
2
点击「使用微软账户登录」可切换为正版登录（设备码授权，官方许可、行业惯例），登录后以正版身份游玩，支持官方皮肤、联机与成就。
3
离线与正版账户互不冲突，随时可切换；使用正版后不再弹出支持正版引导。
小提示：正版账户需要在微软官网购买 Minecraft Java & Bedrock 版，离线启动 10 次后「支持正版」提示会引导你前往购买页。

第 8 步 · 启动游戏

1
回到主页，在版本选择器中确认游戏版本与模组底层。
2
点击中央的启动游戏按钮，启动器会自动完成 Java 检测、参数组装并拉起游戏进程；日志实时显示在底部面板。
3
游戏运行时可随时「停止游戏」；启动器仍可继续操作（下载、浏览资源等）。

第 9 步 · 与好友联机（Terracotta 陶瓦联机）

1
进入「联机」页，点击「创建房间 · 房主」。首次使用启动器会自动准备联机引擎（Terracotta 陶瓦联机），完成后右上角显示「联机引擎运行中」。
2
回到游戏进入单人存档，按 ESC 打开菜单，点击「对局域网开放」并创建局域网世界。陶瓦会自动扫描到你的世界。
3
房间就绪后页面显示邀请码（格式 U/XXXX-XXXX-XXXX-XXXX），点击「复制邀请码」发给好友。无需公网 IP，P2P 直连。
4
好友加入：好友在任意支持陶瓦的启动器（AOURA / HMCL / FMCL 等）中进入联机页，选择「加入房间 · 房客」，输入你的邀请码即可自动组网。
5
加入成功后，好友在游戏「多人游戏」列表双击「陶瓦联机大厅」（或使用页面显示的备用地址添加服务器），即可进入你的世界一起游玩。
6
游玩结束后点击「关闭联机」即可停止引擎；引擎闲置 10 分钟会自动退出，重新开启即可继续。
小提示：联机功能由开源项目 Terracotta | 陶瓦联机（AGPL-3.0）提供，与 HMCL / FMCL 玩家互通；如弹出 Windows 防火墙提示请允许访问。正版与离线账户均可联机。

常见问题

Q：游戏无法启动 / 提示找不到 Java？

进入「设置」确认已开启自动下载 Java 且下载完成；若手动指定，请确认路径指向 javaw.exe。启动前主页会做 Java 友好探测并给出明确提示。

Q：为什么离线账户名必须是英文？

离线账户名即游戏内玩家名，Minecraft 多人服务器普遍要求英文名，强制英文可避免登录服务器被拒，也与正版生态保持一致。

Q：下载速度慢 / 下载失败怎么办？

版本下载走 BMCLAPI 国内镜像，Java 走四源轮询；若某次失败，点击重试或切换网络后重试即可，断点续传会接着下载。

Q：离线账户和正版账户有什么区别？

离线：免费、无需登录、无法使用官方皮肤与正版联机；正版：需在微软官方购买，可登录微软账户游玩，支持官方皮肤、联机与成就。

Q：联机时提示"扫描不到局域网世界"？

确认游戏已进入存档并点击「对局域网开放」创建了局域网世界；部分系统需允许启动器与陶瓦引擎访问网络（防火墙）。若仍失败，尝试关闭联机后重新开启。

Q：加入房间提示"EasyTier 已崩溃"？

这是联机引擎底层的偶发异常，请点击「关闭联机」后重新开启引擎并再次加入；若反复出现，可到问题反馈页向作者反馈。

Q：和好友不同启动器可以联机吗？

可以。陶瓦联机是跨启动器的 P2P 方案，AOURA、HMCL、FMCL 等支持陶瓦的启动器之间可以互相创建 / 加入房间。

Q：为什么我玩的是试玩版？

AOURA 默认下载并启动正式版，不提供试玩版；如果游戏内出现试玩提示，请确认版本来源为「下载中心」且下载完整，必要时重新下载。

Q：模组装上了但没有生效？

确认模组与游戏版本、加载器匹配（如 Fabric 模组需要 Fabric 加载器）；在「模组管理」中确认模组处于启用状态，并已选择带加载器的启动项。
