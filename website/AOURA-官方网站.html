FAQ

常见问题

日志里为什么正常是绿色、异常是红色？

日志配色是独立的，不受界面主题影响。正常运行显示绿色字体，出现异常显示红色字体，方便快速定位问题；日志面板支持一键导出。

游戏变成试玩版（demo）怎么办？

请更新到 4.0.8 及以上版本。旧版本可能在启动参数中误注入 --demo 导致试玩版；当前版本已修复规则引擎。

Java 下载失败怎么办？

启动器内置清华、南大、华为云、兰大四个镜像自动轮询回退，可手动选择下载 Java 8 / 11 / 17 / 21 / 25。

数据存放在哪里？

所有配置、缓存、日志、Java 与游戏文件默认存放在启动器安装目录下，可在设置中自定义位置。

联机需要公网 IP 吗？和好友不同启动器能玩吗？

不需要。AOURA 集成开源项目 Terracotta 陶瓦联机（P2P 方案），创建房间生成邀请码，好友在 AOURA / HMCL / FMCL / PCL 任意支持陶瓦的启动器中输入邀请码即可加入，无需端口映射。
