28.3.1当前
圆归影正 · 跨电脑气泡形态加固，快捷方式图标修复

① 气泡形态加固：部分电脑（GPU 驱动较弱或关闭硬件加速的设备）上，首页的环境气泡与中央启动按钮会变成方形而非圆润气泡。根因是这些元素同时叠加了持续改变圆角的变形动画、多个 transform 动画与背景模糊，在部分内核的合成层上触发圆角裁剪失效、露出方形盒。本版移除会逐帧改变圆角的变形动画与相互竞争的缩放动画，改为固定 border-radius:50% 标准正圆，并新增层叠隔离与不透明背景兜底，把环境气泡纳入面板模糊降级名单，确保任何电脑、任何 DPI 缩放下都稳定显示圆润气泡；② 快捷方式图标修复：开始菜单与桌面快捷方式此前未显式指定图标、依赖目标程序默认图标，且安装后未通知系统刷新，叠加 Windows 图标缓存，偶发显示旧图标或通用图标。本版为两个快捷方式显式指定图标文件与索引，并在安装与卸载完成后调用系统外壳通知（SHChangeNotify）强制刷新图标关联，覆盖安装也能正确显示设计图标。

28.3
芒门直入 · 正版登录直连架构，官网版本号修正

① 官网修复：下载区大标题此前写死为历史版本 v26.7、未随版本迭代更新，本版修正为当前版本，并全局排查杜绝其他写死版本号；② 正版登录直连：旧版要求用户自行去 Azure 注册应用并手动填写 Client ID，普通用户门槛高。本版重构为“内置直连”架构——主进程新增内置公共客户端 ID 常量，登录时优先使用内置 ID、其次用户自定义 ID，用户点击“使用微软账户登录”即可直接走 Xbox/微软官方 OAuth 授权链（设备码 → XBL → XSTS → Minecraft），无需任何手动配置；③ 界面优化：把“应用 Client ID”等配置项折叠进默认收起的“高级设置”，普通用户不暴露；未配置 ID 时弹出包含分步图文指引的统一引导窗（账户类型、允许公共客户端流等关键配置一目了然），首次启动与账户页共用同一引导，不再出现笼统报错。

28.2.3
码察秋毫 · 邀请码本地精确预检，错误一眼定位

本版核对了陶瓦联机上游 Terracotta 的房间码权威格式：必须以 "U/" 开头，后接 4 组、每组恰好 4 个字符（数字与大写字母，用 "-" 分隔），共 21 个字符。旧版前端只在引擎返回错误时给出笼统的"邀请码格式错误"，无法判断具体哪里出错。本版在提交前加入本地精确预检，逐组核对并给出明确提示：哪一组少了几位、是否缺少 "U/" 前缀、分组数不对、含非法字符等，一眼定位问题（例如最后一组只有 3 位时会直接提示"第 4 组只有 3 位、应为 4 位"），格式通过后再交给联机引擎做最终校验。

28.2.2
语定芒安 · 语言包分代彻底适配，修复 Forge 安装与请求头异常

① 语言：第四份日志显示报错再次变化——26.1.2 从 pack format 65 起彻底废弃 supported_formats，只要该字段出现就抛 JsonParseException 并要求移除。本版改为按资源包格式分代生成：format 65 及以上（1.21.9+/26.x）只写 pack_format 与 min/max_format、绝不写 supported_formats；format 18–64 写 pack_format 与 supported_formats；更老版本只写 pack_format。分界精确、各代字段完全合法，资源包不再被移除，主界面稳定中文；② Forge：修复 Forge/NeoForge 安装器运行时 ENOENT——设置中保存的 Java 路径是 JDK 目录而非 java.exe，旧逻辑直接把目录当作可执行文件传给子进程导致失败。本版自动识别目录并补全 bin/java.exe，与游戏启动路径一致；③ 请求头：修复偶发的 ByteString 异常（请求头值含损坏的替换字符 U+FFFD），请求前统一清洗非 Latin1 字符，任何来源的请求头都不会再触发该错误。

28.2.1
稳语归心 · 根治语言包被移除，下载限流秒切源

① 语言：第三份日志定位到真正根因——语言资源包的 pack.mcmeta 同时写了三套字段且上限不一致（supported_formats 上限 84，max_format 却写 255），26.1.2 校验直接抛 JsonParseException（Pack version declaration mismatch），元数据解析失败、资源包被移除，界面回退英文。本版让所有范围字段完全自洽、共用同一区间，并以当前版本为中心适度放宽容错，资源包不再被移除，主界面稳定显示中文；② 下载：修复限流（HTTP 429）时切源判断失效——旧逻辑在官方源作为主地址、镜像作备用排到首位时，内部镜像标识错位，导致镜像 429 无法立即切换、白白退避等待约 9 秒。本版改为任何下载源限流都立即切下一个源、不做退避等待，并激活镜像熔断（连续限流后 30 秒内优先走官方源），下载更快、不再卡顿。

FAQ

常见问题

日志里为什么正常是绿色、异常是红色？

日志配色是独立的，不受界面主题影响。正常运行显示绿色字体，出现异常显示红色字体，方便快速定位问题；日志面板支持一键导出。

游戏变成试玩版（demo）怎么办？

请更新到 4.0.8 及以上版本。旧版本可能在启动参数中误注入 --demo 导致试玩版；当前版本已修复规则引擎。

Java 下载失败怎么办？

启动器内置清华、南大、华为云、兰大四个镜像自动轮询回退，可手动选择下载 Java 8 / 11 / 17 / 21 / 25。

数据存放在哪里？

所有配置、缓存、日志、Java 与游戏文件默认存放在启动器安装目录下，可在设置中自定义位置。

联机需要公网 IP 吗？和好友不同启动器能玩吗？

不需要。AOURA 集成开源项目 Terracotta 陶瓦联机（P2P 方案），创建房间生成邀请码，好友在 AOURA / HMCL / FMCL 等任意支持陶瓦的启动器中输入邀请码即可加入，无需端口映射。
